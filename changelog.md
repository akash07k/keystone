# Keystone changes

- Added the NVDA+slash command layer for foreground and navigator capture, diff, Inspector, Event
  Monitor, Custom UIA Properties, and command help.
- Added the read-only Inspector and its focused and navigator-object workflows, including keyboard
  navigation, copying, loaded-hierarchy search, provider states, and diagnostic Raw UIA guidance.
- Added Event Monitor with scoped monitoring, filters, a four-column event report, retained history,
  and export.
- Added privacy-aware accessibility evidence, typed availability and diagnostic states, output
  controls, and native NVDA diagnostic logging.
- Added Custom UIA property management and diagnostic discovery for scoped, typed definitions.
- Added focused keyboard-first guides for user operation, Inspector and Event Monitor behavior,
  settings and privacy, advanced UIA, evidence interpretation,
  troubleshooting, and contributor workflows.
